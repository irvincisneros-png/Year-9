## uploads/ file named "Year"
`diseases/uploads/` holds one file, 4,407,342 bytes. The name is NOT "Year": it is `Year 9 Topic Booklet - Diseases.pdf` (the space-separated listing in the brief truncated it). `file` says: PDF document, version 1.7, 46 pages. It is the source topic booklet the site was built from. Nothing references it (grep for "uploads" and "Booklet" in the repo finds nothing); the app only uses `images/raw-*.jpg` (pages extracted from it) and `home.jsx` calls raw-00.jpg "topic booklet cover". Not deleted. Recommend removing it from the public repo if the booklet is not meant to be downloadable (4.4 MB, possibly copyrighted school material) or linking it deliberately.
Also unreferenced: `diseases/img/` (hero.png, immune.png, pathogens.png) and `diseases/images/raw-05,06,10.jpg`.
